2. Custom Styled Buttons

Gradient Button

Button with gradient background and hover effect.

<style> .btn-custom-1 { background: linear-gradient(45deg, #4361ee, #3a0ca3); border: none; color: white; transition: all 0.3s ease; } .btn-custom-1:hover { background: linear-gradient(45deg, #3a0ca3, #4361ee); transform: translateY(-2px); box-shadow: 0 5px 15px rgba(67, 97, 238, 0.4); } </style> <button class="btn btn-custom-1 btn-lg">Gradient Button</button>
Border Hover Effect

Button with border that fills on hover.

<style> .btn-custom-2 { background-color: transparent; border: 2px solid #4361ee; color: #4361ee; transition: all 0.3s ease; } .btn-custom-2:hover { background-color: #4361ee; color: white; transform: scale(1.05); } </style> <button class="btn btn-custom-2 btn-lg">Border Hover</button>
Rounded Pill Button

Button with rounded pill shape and color change on hover.

<style> .btn-custom-3 { background-color: white; border: 2px solid #2ecc71; color: #2ecc71; border-radius: 50px; padding: 10px 25px; font-weight: 600; transition: all 0.3s ease; } .btn-custom-3:hover { background-color: #2ecc71; color: white; box-shadow: 0 5px 15px rgba(46, 204, 113, 0.4); } </style> <button class="btn btn-custom-3">Pill Button</button>
Animated Button

Button with animated shine effect on hover.

<style> .btn-custom-4 { background-color: #f39c12; color: white; border: none; border-radius: 8px; overflow: hidden; position: relative; } .btn-custom-4:before { content: ''; position: absolute; top: 0; left: -100%; width: 100%; height: 100%; background: rgba(255, 255, 255, 0.2); transition: all 0.5s ease; } .btn-custom-4:hover:before { left: 100%; } </style> <button class="btn btn-custom-4">Shine Effect</button>

4. Button Groups & Toolbars

Button Groups

Group a series of buttons together on a single line.

<div class="btn-group" role="group" aria-label="Basic example"> <button type="button" class="btn btn-primary">Left</button> <button type="button" class="btn btn-primary">Middle</button> <button type="button" class="btn btn-primary">Right</button> </div> <div class="btn-group-vertical" role="group" aria-label="Vertical button group"> <button type="button" class="btn btn-outline-success">Top</button> <button type="button" class="btn btn-outline-success">Middle</button> <button type="button" class="btn btn-outline-success">Bottom</button> </div>
Responsive Button Group

Button group that wraps on smaller screens.

<style> .btn-group-responsive { flex-wrap: wrap; } </style> <div class="btn-group btn-group-responsive" role="group" aria-label="Responsive button group"> <button type="button" class="btn btn-outline-primary">Home</button> <button type="button" class="btn btn-outline-primary">Profile</button> <button type="button" class="btn btn-outline-primary">Messages</button> <button type="button" class="btn btn-outline-primary">Settings</button> <button type="button" class="btn btn-outline-primary">Help</button> </div>
