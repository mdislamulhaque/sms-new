Scrollable Responsive Modal
Long Content Area

This modal has scrollable content. When the content exceeds the modal height, it becomes scrollable.

Section 1: Introduction

Scrollable modals are perfect for content that may be too long for a standard modal window.

On mobile devices, this allows users to scroll through content without the modal becoming too tall.

Section 2: Responsive Behavior

The scrollable area automatically adjusts based on screen height. On taller screens, you'll see more content before scrolling.

On shorter mobile screens, the scrollable area will be smaller to ensure the modal fits on screen.

Section 3: Usage Examples
  • Terms and conditions documents
  • Long forms with many fields
  • Detailed product descriptions
  • Article previews
  • Settings panels with many options
Section 4: Implementation

To create a scrollable modal, add the .modal-dialog-scrollable class to the modal dialog element.

This makes only the modal body scrollable while keeping the header and footer fixed.

Section 5: Accessibility

Scrollable modals maintain keyboard accessibility. Users can tab through focusable elements and use arrow keys to scroll.

The scrollbar appearance adapts to different operating systems and devices.

Note: You've reached the end of the scrollable content. This modal demonstrates how long content can be handled responsively.
